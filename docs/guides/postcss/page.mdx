# PostCSS & Tailwind

Mountaineer uses Vite for CSS in both development and production. Vite automatically
loads `postcss.config.js` or `postcss.config.mjs` from your `views` directory, so no
Python builder or Vite dependency in your project is required.

Install the PostCSS plugins your configuration uses:

```bash
npm install -D postcss tailwindcss autoprefixer
```

Then configure PostCSS normally:

```javascript title="views/postcss.config.js"
module.exports = {
  plugins: {
    tailwindcss: {},
    autoprefixer: {},
  },
};
```

```css title="views/app/main.css"
@tailwind base;
@tailwind components;
@tailwind utilities;
```

During development Vite serves the stylesheet directly. Production builds emit
`views/app/main.css` as `/static/app_main.css`, which can be added to global metadata:

```python
controller = AppController(
    config=AppConfig(),
    global_metadata=Metadata(
        links=[LinkAttribute(rel="stylesheet", href="/static/app_main.css")]
    ),
)
```
