# Layout Organization

Layouts follow the view directory tree. Put shared elements in a parent `layout.tsx`, or use separate folder groups when sections need different layouts.

## Default Layout Structure

Each layout applies to pages in its directory and subdirectories:

```
views/
└── app/
    ├── layout.tsx         # Root layout (applies to all pages)
    ├── home/
    │   └── page.tsx       # Uses root layout
    └── dashboard/
        ├── layout.tsx     # Dashboard layout (applies to all dashboard pages)
        ├── home/
        │   └── page.tsx   # Uses both root and dashboard layouts
        └── settings/
            └── page.tsx   # Uses both root and dashboard layouts
```

In this structure, when rendering `dashboard/home/page.tsx`, the page will be wrapped by both the `dashboard/layout.tsx` and the root `app/layout.tsx`.

## Optional Layout Structure with (root) Folder

To give the homepage a layout that the dashboard won't inherit, place it in a separate `(root)` group:

```
views/
└── app/
    ├── (root)/            # Root group
    │   ├── layout.tsx     # Layout only applies within this group
    │   └── home/
    │       └── page.tsx   # Uses the (root) layout
    └── dashboard/         # Separate section not using the (root) layout
        └── page.tsx       # Doesn't use any layout
```

`(root)/layout.tsx` wraps the homepage. The dashboard sits outside that group and inherits no layout in this example. You can use the same separation for a marketing site and an authenticated app.

## Nested Layout Groups

Groups can nest. Here, the admin dashboard uses both group layouts, while the auth page uses neither:

```
views/
└── app/
    ├── (root)/
    │   ├── layout.tsx
    │   ├── home/
    │   │   └── page.tsx   # Uses only the (root) layout
    │   └── (admin)/
    │       ├── layout.tsx # Admin layout
    │       └── dashboard/
    │           └── page.tsx # Uses both (root) and (admin) layouts
    └── auth/
        └── page.tsx       # Doesn't use any layout
```

## Implementation Details

A folder name wrapped in parentheses, such as `(root)` or `(admin)`, identifies a layout group. Group names organize views without changing their URLs.
