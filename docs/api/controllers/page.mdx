# Controllers

Controllers define the Python logic for views and layouts. Their `render()` methods supply page data, and their actions handle client requests. `AppController` registers these controllers with the application.

## Metadata

`Metadata` defines elements in the page's HTML `<head>`, including stylesheets,
scripts, and meta tags. `ScriptAttribute`, `LinkAttribute`, and `MetaAttribute`
map to their corresponding HTML elements. Helpers such as `ViewportMeta` build
common structured values.
